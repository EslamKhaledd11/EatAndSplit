# Eat-N-Split

A simple and intuitive React application that makes it easy to split bills with your friends. Say goodbye to the hassle of math when you're hanging out, and never forget who owes who!

## Features

- **Add Friends**: Quickly add friends to your list simply by entering their name. (Auto-generates an avatar for them!)
- **Track Balances**: Each friend has an automatically updating balance, color-coded so you instantly know who owes who money.
- **Split Bills**: Simply input the total bill value and your part of the expense. The app instantly figures out your friend's part!
- **Dynamic Updates**: Once you split a bill, the balances immediately update.

## Technologies Used

- **React 19**
- **Vite**
- **CSS** for clean, vanilla styling.

## Getting Started

Follow these steps to run the project locally on your machine.

### Prerequisites

Make sure you have Node.js and npm installed on your machine.

### Installation

1. **Clone the repository:**
   ```bash
   git clone <your-repository-url>
   ```

2. **Navigate to the project directory:**
   ```bash
   cd eat_n_split
   ```

3. **Install dependencies:**
   ```bash
   npm install
   ```

4. **Start the development server:**
   ```bash
   npm run dev
   ```

5. **Open in your browser:**
   Navigate to the local URL provided by Vite in your terminal (usually `http://localhost:5173`). Have fun splitting!
